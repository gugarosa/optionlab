# optionlab

A design lab for agent-proposed UI options. See alternatives live in your own app,
pick what works, and hand one choices file back to your coding agent.

**In development.** Not published to npm.

The reviewer opens one HTML file. The agent uses a dependency-free Node CLI.
Options are real pages, not screenshots or isolated component demos.

## Contributing

Requires Node 20 or newer. Run `npm ci`, then `npm test`.
See [AGENTS.md](AGENTS.md) for the repository map and contributor rules.
